A second brain that grows from your documents.

Drop in briefs, call notes, emails or personal notes. Threadline has Claude read them, then turns them into linked notes you can open in Obsidian and a map Claude can follow. Every connection quotes the document it came from.

Who it's for: anyone with scattered notes and documents, such as account managers, marketers, consultants and students, who wants answers traced back to the source.

        Recommended · free
        
Your GitHub repository is the brain

        
Add documents on github.com or from your computer. GitHub reads them, updates the notes and commits them back. Ask questions by opening an issue.

        
  1. Make a private copy with "Use this template"
  2. Add ANTHROPIC_API_KEY as a secret and set THREADLINE_ENABLED
  3. Drop documents into inbox/business/ or inbox/personal/
  4. Open the repository folder in Obsidian, if you like

      

      

        
On your own computer

        
Keep everything local, next to your Obsidian vault. Same notes, same map.

        
  1. Download the code and add your key to .env
  2. Put documents in inbox/
  3. Run npm run build, then npm run ask -- "your question"
  4. Open the folder in Obsidian, or point Claude Code at it: brain/CLAUDE.md tells it how to use the map

      

    

  


  

    
Design decisions

    

      
Every link has a receipt
Each connection quotes its document. If Claude suggests a link and the quote isn't really there, it's thrown away. Links are marked stated, inferred or unclear, so guesses never look like facts.

      
Documents are untrusted
Hidden text, like the instructions buried in the example's vendor proposal, is removed before Claude reads anything. Bank details, card numbers and keys are redacted. A document that tries to instruct the AI adds nothing.

      
You stay in charge
Write under "Your notes" or mark a note confirmed: true and it survives every rebuild. Delete a document and exactly what it contributed disappears. Your own notes are never touched.
