# Security basics

Owner: IT and Security team
Last edited time: October 1, 2026 4:45 PM

- Use the company password manager for every work account.
- Turn on two-factor authentication everywhere it is offered.
- Report a suspicious email in #security within 1 hour, even if you clicked it. Nobody gets in trouble for reporting.
- Never share passwords, API keys or customer data in Slack or email.
